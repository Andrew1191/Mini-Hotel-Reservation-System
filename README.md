# Mini Hotel Reservation System
#  Mini Hotel Reservation System  A console-based Hotel Management System developed in C++ to automate room bookings, manage customer accounts, and handle admin operations. The system uses file handling to persist data and includes advanced validation algorithms.  ##  Features & Functionalities  ### 1. Data Management & Structs * Organized complex data using structures: `date`, `customer`, `room`, `reservation`, `review`, and `admin`. * Manages 5 floors with 10 rooms each (Single, Double, Suite) with automated pricing and offers.  ### 2. Authentication System (Customer & Admin) * **Customers:** Can sign up, log in, check availability, book rooms, view reservation history, and add reviews. * **Admin:** Has a dedicated portal to manage all reservations, view reviews, cancel or modify bookings on behalf of customers.  ### 3. Core Booking Logic * **Dynamic Availability Checking:** Checks if a room is available in a specific date range by verifying overlaps with existing active reservations. * **Billing System:** Calculates total cost based on the number of nights and additional services (Sea View, Meals, Shuttle, Comfort Bed). * **Reservation Status:** Categorizes reservations dynamically into (Active, Completed, Cancelled) based on the current date.  ### 4. Data Persistence (File I/O) * Saves and loads all data (Customers, Reservations, Reviews) using `.txt` files (`customers.txt`, `reservations.txt`, `reviews.txt`) to ensure data is not lost after the program closes.  ---  ##  Edge Cases Handled (Robustness)  The system is designed to prevent crashes and handle invalid inputs gracefully: * **File Safety:** If data files do not exist during startup, the program continues running seamlessly and creates them upon exit. * **Advanced Date Validation:**    * Prevents users from booking in the past by comparing inputs with the system's current real-time date using `<ctime>`.   * Validates that the end date is strictly after the start date, and checks for valid days/months[cite: 1]. * **Credit Card Validation:** Implements a mathematical algorithm (Luhn Algorithm) to validate credit cards (checks length 13-19 and validates the digit sum)[cite: 1]. * **Username & Email Constraints:** Prevents duplicate usernames during sign-up and ensures emails contain an `@` symbol[cite: 1]. * **Booking Overlaps:** Accurately prevents booking the same room twice in overlapping date ranges[cite: 1]. * **Review Limitations:** Customers can only review a room if they have an active booking[cite: 1]. The system also filters reviews to only display those submitted within the last 30 days[cite: 1]. * **Admin Override:** Admins bypass credit card validation when making reservations for customers manually[cite: 1].
